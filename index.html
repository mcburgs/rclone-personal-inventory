Personal-use desktop integration

Rclone Personal Inventory

This is an informational page for a privately operated rclone connection to Google Drive. The application is used by its owner to inventory files, compare file metadata and checksums, and maintain personal backups.

How it works

Rclone runs locally on the owner's computer. Google OAuth is used to authorize access to the owner's Google Drive. Read-only access is used for inventory and verification. A separate, deliberately authorized connection may use access limited to files created or opened by the application for backup operations.

This website is not the application itself. It has no sign-in form, does not request Google account access, and does not receive or store Google Drive files, credentials, or file listings.
